# Лабораторная работа 2.
___
Я добавила к коду реализации перемножения на с++ (лабораторная работа 1) поддержку OpenMP. Также выполнила проверку на правильность перемножения.
В таблице приведено время выполнения программы в секундах для разного количества потоков:

| Размер матрицы (N) | 1 поток | 2 потока | 4 потока | 8 потоков |
|:------------------:|:---------------:|:---------------:|:---------------:|:---------------:|
| 200 | 0.180           | 0.093           | 0.053           | 0.039           |
| 400 | 1.449           | 0.733           | 0.419           | 0.270           |
| 800 | 11.598          | 5.857           | 3.078           | 2.144           |
| 1200 | 39.145          | 19.765          | 10.611          | 8.032           |
| 1600 | 93.812          | 62.354          | 35.889          | 22.564          |
| 2000 | 180.973         | 102.838         | 53.315          | 39.380          |

Зависимость времени выполнения алгоритма от размера матриц представлена на графике:
![](graph.png)
Вывод: Тестирование показало, что сложность алгоритма перемножения матриц напрямую зависит от их размера. Применение OpenMP позволяет значительно ускорить этот процесс, существенно сокращая время выполнения для больших матриц. Тем не менее, для малых матриц наблюдается тенденция к увеличению общего времени из-за накладных расходов на управление потоками.
