| 400            | 0.7444    | 0.3895     | 0.1931     | 0.1425      |
| 800            | 6.0052    | 3.0308     | 1.6284     | 1.1614      |
| 1200           | 20.3309   | 10.1855    | 5.4195     | 3.7517      |
| 1600           | 47.7665   | 24.1610    | 15.3383    | 9.1835      |
